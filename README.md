# Addison Road Laundrette

One-page website for Addison Road Laundrette, 81 Addison Rd, Manly NSW 2095.

Static HTML (Tailwind via CDN) — no build step. Deployed on Netlify.

- Inquiry form uses Netlify Forms (form name: `inquiry`). Set up email notifications in Netlify → Site → Forms.
- Gallery images expected in the repo root: `storefront-1.jpg`, `storefront-2.jpg`, `interior.jpg`, `street-view.jpg`.
